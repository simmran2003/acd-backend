# AI Code Detective

AI-powered code investigation and bug patching platform.

## Overview

AI Code Detective analyzes software repositories to identify
potential bugs, investigate root causes, generate patches,
and validate proposed fixes.

## Technology Stack

- FastAPI
- AWS
- DynamoDB
- S3
- OpenAI
- Terraform
- GitHub Actions
